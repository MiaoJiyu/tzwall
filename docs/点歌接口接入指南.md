# 点歌列表接口接入指南

> 面向需要对接「校园点歌」数据的客户端/第三方。该接口为**公开只读**，无需登录或 Token。

## 1. 用途
获取站点点歌列表（可按状态筛选、分页），用于在 OTHER 端展示「大家点了什么歌」。

## 2. 请求方式
- **方法**：`GET`
- **地址**：`https://tzwall.miaojiyu.top/api/songs`
- **认证**：无（公开端点）

### Query 参数
| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `page` | int | 1 | 页码，从 1 开始 |
| `page_size` | int | 20 | 每页数量，1–50 |
| `status` | string | 全部 | 可选：`pending`(待播放) / `played`(已播放) / `canceled`(已取消) / `all` |

### 示例
```bash
curl "https://tzwall.miaojiyu.top/api/songs?page=1&page_size=20&status=pending"
```

## 3. 返回内容
统一响应壳：`{ "code": 0, "message": "ok", "data": { ... } }`（`code != 0` 表示失败）。

`data` 结构：
| 字段 | 类型 | 说明 |
|---|---|---|
| `items` | array | 点歌列表（按创建时间倒序） |
| `total` | int | 总条数 |
| `page` | int | 当前页码 |
| `page_size` | int | 每页数量 |

`items[]` 单条字段：
| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | int | 点歌记录 ID |
| `user_id` | int | 提交者用户 ID |
| `title` | string | 歌名 |
| `artist` | string | 歌手 |
| `note` | string | 留言 |
| `status` | string | `pending` / `played` / `canceled` |
| `created_at` | string | 创建时间（RFC3339） |
| `username` | string | 提交者用户名 |

### 响应示例
```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "items": [
      { "id": 12, "user_id": 3, "title": "晴天", "artist": "周杰伦", "note": "想听", "status": "pending", "created_at": "2026-10-20T12:00:00+08:00", "username": "Jiyu" }
    ],
    "total": 1,
    "page": 1,
    "page_size": 20
  }
}
```

## 4. 调用注意事项
- **只读公开**：仅支持读取列表；提交点歌、查看配额等需登录（`POST /api/songs` 等），不在本指南范围。
- **频率限制**：受站点统一速率策略约束，超限返回 `HTTP 429` / `code 429`，请做退避重试，避免高频轮询（建议 ≥ 30s）。
- **分页**：`page_size` 上限 50；数据量大时请配合 `page` 遍历，勿一次性拉全量。
- **状态口径**：`pending`=待播放、`played`=已播放、`canceled`=已取消；不传 `status` 返回全部状态。
- **字段兼容**：以本指南为准；后端可能新增字段，客户端应忽略未知字段而非报错。
- **时间格式**：`created_at` 为带时区 RFC3339 字符串，展示端自行格式化。
