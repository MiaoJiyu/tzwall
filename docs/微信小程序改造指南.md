# 微信小程序改造指南（登录 / 首次注册 / 个人中心绑定）

> 适用：后端已升级为「小程序首次登录必须填写用户名+密码注册」「网页已登录账号可用绑定码绑定微信」。
> 项目路径：`./tzwall/`；小程序建议放在 `./tzwall/miniprogram/`。

## 一、前置配置
1. **AppID**：`project.config.json` 的 `appid` 必须与后台「系统配置 → 注册与登录 → 微信小程序 AppID」一致。
2. **请求域名**：小程序后台 → 开发管理 → 服务器域名 → request 合法域名，填后端 HTTPS 域名（如 `https://your.domain`）。
3. **BASE_URL**：统一指向 `https://your.domain/api`。本地联调可用 `http://127.0.0.1:10002/api`，并在开发者工具勾选「详情 → 本地设置 → 不校验合法域名」。
4. 小程序端**绝不放 AppSecret**；openid 只能由后端 jscode2session 获取。

## 二、接口契约（统一响应 `{ code, message, data }`，`code=0` 成功）
鉴权头：`Authorization: Bearer <token>`。

### 1) 登录
`POST /api/auth/wechat/login`，body `{ "code": "<wx.login 的 code>" }`
- 已绑定账号：`data = { token, user, is_new:false }`
- 首次（未绑定）：`data = { need_register: true, ticket: "<票据>" }`
  - ticket 10 分钟有效、一次性；客户端拿不到 openid，无法伪造。

### 2) 首次注册（拿到 ticket 后）
`POST /api/auth/wechat/register`，body `{ ticket, username, password }`
- username：6-12 位（字母/数字/部分符号，与网页一致）
- password：6-64 位
- 成功：`data = { token, user, is_new:true }`，账号自动绑定该微信（`wx_openid`）
- 失败：票据过期 / 用户名已存在 / 长度不符等，读 `message`

### 3) 绑定微信（网页已登录账号 → 在小程序绑定）
> 流程：用户在**网页**点「绑定微信」拿到 8 位**绑定码** → 在小程序输入 → 小程序用 `wx.login` 的 code 提交。
`POST /api/auth/wechat/bind-code/confirm`，body `{ bind_code, code }`
- `bind_code`：网页展示的 8 位码（10 分钟有效、一次性）
- `code`：`wx.login()` 返回的 code
- 成功：`code=0`；失败：`41009`（绑定码无效/过期）、`该微信已绑定其他账号` 等

### 4) 当前用户（刷新绑定状态）
`POST /api/auth/me`（需 token）→ `data = user`，含 `wechat_bound` / `qq_bound`。

### 5) （可选）修改资料
`POST /api/auth/profile`（需 token），body `{ nickname, avatar, wechat, qq, phone, profile_public, public_fields }`

## 三、请求封装 `utils/request.js`
```js
const BASE_URL = 'https://your.domain/api'
function request(method, path, body) {
  return new Promise((resolve, reject) => {
    const token = wx.getStorageSync('token')
    wx.request({
      url: BASE_URL + path,
      method,
      data: body || {},
      header: {
        'Content-Type': 'application/json',
        ...(token ? { Authorization: 'Bearer ' + token } : {}),
      },
      success(res) {
        const b = res.data || {}
        if (b.code === 0) return resolve(b.data)
        if (b.code === 40100) {
          wx.removeStorageSync('token')
          wx.removeStorageSync('user')
          wx.reLaunch({ url: '/pages/login/login' })
        }
        wx.showToast({ title: b.message || '请求失败', icon: 'none' })
        reject(b)
      },
      fail(err) {
        wx.showToast({ title: '网络错误，请检查域名配置', icon: 'none' })
        reject(err)
      },
    })
  })
}
module.exports = {
  get: (p) => request('GET', p),
  post: (p, d) => request('POST', p, d),
}
```

## 四、登录逻辑 `utils/auth.js`
```js
const request = require('./request')
function wxLogin() {
  return new Promise((resolve, reject) => {
    wx.login({ success: ({ code }) => (code ? resolve(code) : reject('wx.login 失败')), fail: reject })
  })
}
async function login() {
  const code = await wxLogin()
  const data = await request.post('/auth/wechat/login', { code })
  if (data.need_register) {
    wx.navigateTo({ url: '/pages/register/register?ticket=' + encodeURIComponent(data.ticket) })
    return { needRegister: true }
  }
  wx.setStorageSync('token', data.token)
  wx.setStorageSync('user', data.user)
  return { ok: true, user: data.user }
}
module.exports = { login }
```

## 六、注册页 `pages/register/register`
```js
const request = require('../../utils/request')
Page({
  data: { ticket: '', username: '', password: '' },
  onLoad(q) { this.setData({ ticket: q.ticket || '' }) },
  onInput(e) { this.setData({ [e.currentTarget.dataset.field]: e.detail.value }) },
  async submit() {
    const { ticket, username, password } = this.data
    if (!/^[A-Za-z0-9!@#$%^&*()_+\-=\[\]{}|;:,.<>?]{6,12}$/.test(username)) {
      return wx.showToast({ title: '用户名需 6-12 位（字母/数字）', icon: 'none' })
    }
    if (password.length < 6 || password.length > 64) {
      return wx.showToast({ title: '密码需 6-64 位', icon: 'none' })
    }
    try {
      const d = await request.post('/auth/wechat/register', { ticket, username, password })
      wx.setStorageSync('token', d.token)
      wx.setStorageSync('user', d.user)
      wx.showToast({ title: '注册成功' })
      wx.reLaunch({ url: '/pages/index/index' })
    } catch (e) {
      /* 错误已由 request 统一 toast */
    }
  },
})
```

```xml
<input bindinput="onInput" data-field="password" password placeholder="密码（6-64位）" />
<button bindtap="submit">完成注册</button>
```

## 八、绑定页 `pages/bind/bind`
```js
const request = require('../../utils/request')
Page({
  data: { bindCode: '' },
  onInput(e) { this.setData({ bindCode: e.detail.value }) },
  async submit() {
    const bindCode = this.data.bindCode.trim().toUpperCase()
    if (!bindCode) return wx.showToast({ title: '请输入绑定码', icon: 'none' })
```

## 十、错误码与处理
| code | 含义 | 处理 |
|---|---|---|
| 0 | 成功 | — |
| 40100 | 登录失效 | 清 token，回登录页 |
| 41009 | 票据/绑定码无效或过期 | 提示重新获取（回网页重新生成绑定码 / 重新 wx.login） |
| 其他非 0 | 业务错误 | 直接 toast `message` |

常见业务 message：`用户名已存在`、`密码长度需 6-64 位`、`该微信已绑定其他账号`、`第三方登录未配置或暂不可用`。

## 十一、验收清单
- [ ] 首次点登录 → 跳注册页 → 填用户名+密码 → 成功进首页，账号已绑定微信。
- [ ] 再次登录 → 直接进首页（不再要求注册）。
- [ ] 网页「绑定微信」拿绑定码 → 小程序输入 → 绑定成功；网页刷新显示「已绑定」。
- [ ] 无效/过期绑定码 → 友好提示。
- [ ] token 失效(40100) → 自动回登录页。
- [ ] 域名未配置/非 HTTPS → 请求失败并按提示排查。

## 十二、常见问题
- **点击无反应**：检查按钮是否 `bindtap` 绑定了已定义的方法、页面是否已注册在 `app.json`。
- **请求失败**：确认 request 合法域名、HTTPS、`BASE_URL` 带 `/api`。
- **首登报错**：确认处理了 `need_register` 分支并跳注册页。
- **AppSecret 40125**：后端密钥读取已修复（自动解密）；确保后台填的是**小程序 AppSecret**（与小程序 AppID 配套）。
- **绑定失败 41009**：绑定码 10 分钟过期或已使用，回网页重新生成。
- **网页微信绑定**：若后台未配置「微信网页应用 AppID/AppSecret」，网页端不会走扫码，而是给出绑定码流程；两者都未配置时会提示"暂未开放"。

## 十三、解绑后的状态同步（重要）
「登录态」与「绑定关系」是两套独立判断：解绑只清 `wx_openid`，**不会自动让小程序里已有的 JWT 失效**。若小程序刷新时只看"有没有 token"，就会一直显示"微信登录成功"。

**后端已做的处理**：网页「解绑微信/QQ」时会使该账号**既有 token 全部失效**（并给当前网页回发新 token）。因此：
- 小程序持有的**旧 token** 下一次请求会收到 `40100 登录凭证已失效`；
- 小程序应清除本地 token，重新 `wx.login` → `/auth/wechat/login`；
- 此时该微信 openid 已解绑，接口返回 `need_register`（而不是 token），**不会再显示"微信登录成功"**。

**小程序端请确保**：
1. 请求封装遇到 `40100` → 清 `token`/`user` 并跳登录页（指南 `utils/request.js` 已如此）。
2. 判断"微信登录状态"以 `/auth/me` 的 `wechat_bound` 为准，**不要用本地成功标记**：
```js
async onShow() {
  const u = await request.post('/auth/me') // 旧 token 失效会走 40100 分支自动重登
  wx.setStorageSync('user', u)
  this.setData({ wechatBound: !!u.wechat_bound })
}
```
3. 不要把"已登录"等同于"已绑定微信"：文案用 `wechat_bound ? '已绑定微信' : '未绑定微信'`。

## 十四、网页扫码即登（方案 B：小程序码携带 scene）

> 场景：用户在网页登录页点「微信登录 → 小程序登录」，用微信扫网页上的小程序码，小程序**自动确认**，网页随即自动登录。全程无需在网页输入账号密码。

### 14.1 流程
```
网页                        后端                          小程序
 │ 点「微信登录→小程序」       │                             │
 │ POST /auth/web-login/session│ 建票据T(5分钟,一次性)         │
 │ ← {ticket:T}               │                             │
 │ POST /auth/web-login/qrcode│ 调微信 getwxacodeunlimit     │
 │ ← 小程序码(base64, scene=T) │                             │
 │ 展示小程序码，每2s poll     │                             │
 │                            │  用户扫码 → onLoad(scene=T)  │
 │                            │  POST /auth/web-login/confirm {ticket:T, code:wx.login}
 │                            │ ← jscode2session 校验微信 → 找已绑定账号 → 写兑换码
 │ POST /auth/web-login/poll  │                             │
 │ ← {status:confirmed, exchange_code}                       │
 │ POST /auth/social/exchange │ → token + user               │
 │ 自动登录成功，跳首页         │                             │
```

### 14.2 接口契约
| 方法/路径 | 权限 | 说明 |
|---|---|---|
| `POST /api/auth/web-login/session` | 公开 | 建票据 → `{ticket, expires_in:300}` |
| `POST /api/auth/web-login/qrcode` | 公开 | body `{ticket}` → `{image_base64}`（带 scene 的小程序码） |
| `POST /api/auth/web-login/confirm` | 公开 | body `{ticket, code}`（`code` 为 `wx.login` 的 code） |
| `POST /api/auth/web-login/poll` | 公开 | body `{ticket}` → `{status, exchange_code}` |
| `POST /api/auth/social/exchange` | 公开 | body `{code}` → `{token, user, is_new}` |

`status`：`pending`（等待确认）/ `confirmed`（携带一次性兑换码）/ `expired`（票据失效，网页需刷新）。

### 14.3 后台配置
「系统配置 → 注册与登录 → **小程序登录确认页路径**」（`miniprogram_confirm_page`），默认 `pages/web-login/web-login`。
必须与小程序 `app.json` 注册的页面路径**一致**（改这里就要同步改小程序）。

### 14.4 小程序新增页面 `pages/web-login/web-login`
同时支持两种进入方式：
- **扫码进入**：`onLoad(query)` 收到 `scene`（即票号）→ 自动确认；
- **手动进入**：从「我的」页进入 → 手动输入网页上显示的票号。

```js
// pages/web-login/web-login.js
const request = require('../../utils/request')

Page({
  data: { ticket: '', status: '' },

  onLoad(query) {
    // 方式一：扫网页小程序码进入，scene 即网页登录票号
    const scene = query.scene ? decodeURIComponent(query.scene) : ''
    if (scene) {
      this.setData({ ticket: scene })
      this.confirm()
    }
  },

  onInput(e) {
    this.setData({ ticket: e.detail.value })
  },

  async confirm() {
    const ticket = (this.data.ticket || '').trim().toUpperCase()
    if (!ticket) return wx.showToast({ title: '请输入票号', icon: 'none' })
    this.setData({ status: '确认中…' })
    try {
      const { code } = await new Promise((resolve, reject) =>
        wx.login({ success: resolve, fail: reject }))
      await request.post('/auth/web-login/confirm', { ticket, code })
      wx.showToast({ title: '已允许网页登录', icon: 'success' })
      setTimeout(() => wx.navigateBack(), 800)
    } catch (e) {
      this.setData({ status: '' })
      // 错误已由 request 统一 toast；常见：票号过期 / 该微信尚未注册账号
    }
  },
})
```

```xml
<!-- pages/web-login/web-login.wxml -->

  <view class="title">网页登录确认</view>
  <view class="tip">在电脑或手机浏览器打开「校园墙」登录页，输入其上显示的票号，即可让该浏览器自动登录。</view>
```

### 14.7 错误与处理
| 返回 | 含义 | 处理 |
|---|---|---|
| `41009` 登录会话已过期/已被使用 | 票号 5 分钟过期或一次性 | 回网页点「刷新二维码」重新扫 |
| `该微信尚未注册账号，请先在小程序完成注册` | 该微信没绑过账号 | 引导先走小程序登录/注册流程 |
| `errcode=40029 invalid code` | `wx.login` 的 code 无效或重复使用 | 重新 `wx.login` 再提交 |
| `41024` 小程序码生成失败 | 小程序 AppID/Secret 未配或权限不足 | 检查后台「微信小程序 AppID/AppSecret」 |

### 14.8 安全说明
- 票号一次性、5 分钟有效；`confirm` 必须经 `wx.login` + 服务端 `jscode2session` 校验，**客户端伪造 openid 无效**。
- 网页最终拿到的是**一次性兑换码**，再经 `/auth/social/exchange` 换 JWT；JWT 不出现在 URL 中。
- 只有**已注册/绑定账号**的微信才能确认登录，未注册微信会被明确拒绝。
- 四个端点均按「访问权限」矩阵限流（session 30/小时、qrcode 60/分钟、confirm 60/小时、poll 300/分钟，按 IP）。

### 14.9 验收清单
- [ ] 网页点「微信登录 → 小程序登录」→ 显示小程序码 + 票号
- [ ] 小程序「扫一扫」扫该码 → 自动进入 web-login 页并确认 → 网页自动登录并跳首页
- [ ] 未扫码时网页持续显示"等待确认"；5 分钟后显示已失效，可点「刷新二维码」重来
- [ ] 手动进入 web-login 页输入票号也能确认成功
- [ ] 未注册的微信确认 → 提示"请先在小程序完成注册"
- [ ] 同一票号确认两次 → 第二次提示已被使用
- [ ] 确认后 `auth/me` 的 `wechat_bound` 为 true
